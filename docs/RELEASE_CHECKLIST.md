# Release checklist

- [ ] Version number updated
- [ ] CHANGELOG.md updated
- [ ] Docker image builds cleanly
- [ ] Fresh install tested
- [ ] Existing JSON backup imported into fresh install
- [ ] New JSON backup exported and restored
- [ ] Desktop smoke test completed
- [ ] Mobile smoke test completed
- [ ] No demo/private health data in repository
- [ ] No secrets, `.env`, databases or backups committed
- [ ] Git tag created
- [ ] GitHub Release notes prepared
